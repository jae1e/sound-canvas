# TTS listening samples (on-device candidates)

Generated 2026-11-03 on a 16-core Linux PC, CPU only, 4 threads per model (`num_threads=4` / `--cpu-threads 4`), Python 3.14, onnxruntime 1.31.1, sherpa-onnx 2.0.1. WAVs are generated by `scripts/` and are meant to be gitignored; only this README and `scripts/` are tracked.

Status of claims: license text and sizes were read from the downloaded packages and Hugging Face / GitHub on 2026-11-03 (verified). RTF values are measured on this PC (verified for this PC only; an Android phone will differ a lot). Subjective quality is NOT assessed here - the files were not listened to by the generator. As an objective proxy, every WAV was round-tripped through SenseVoice ASR (`scripts/asr_check.py`); transcripts are in the file list below.

`en_compare.wav` (order): 0.7 s silence then, in this order: Supertonic 3 `f1` E1, MOSS-TTS-Nano `ava` E1, Kitten nano `bella` E1, Kitten mini `bella` E1, Kokoro `af_heart` E1 (each preceded by 0.7 s silence).

## Notes, caveats and license surprises

- **Supertonic 3**: weights are BigScience OpenRAIL-M, not OSI-open. Commercial use and redistribution are allowed, but you must pass the Attachment A use restrictions (no illegal use, impersonation/deception, discrimination, medical advice, etc.) to downstream users and ship the license text. 'Derivatives of the Model' explicitly includes distillation / training another model on its synthetic output - do not use its audio as training data. The sherpa-onnx package's bundled LICENSE file is the MIT text of the sample code only, which understates the weight license. Upstream repo `supertone-inc/supertonic` is archived. Source: https://huggingface.co/Supertone/supertonic-3 (license `openrail`), https://huggingface.co/Supertone/supertonic-3/blob/main/LICENSE, package https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models (docs https://k2-fsa.github.io/sherpa/onnx/tts/supertonic.html). The int8 files come from the sherpa-onnx conversion (derivative, same license applies). Voice names f1/m1 are inferred (10 voices; pitch check: sid 0 about 183 Hz, sid 5 about 135 Hz, so sid 0-4 are probably F1-F5 and 5-9 M1-M5); sherpa docs do not label them.
- **MOSS-TTS-Nano**: Apache-2.0 (root LICENSE present in https://github.com/OpenMOSS/MOSS-TTS-Nano; HF repos https://huggingface.co/OpenMOSS-Team/MOSS-TTS-Nano-100M-ONNX and https://huggingface.co/OpenMOSS-Team/MOSS-Audio-Tokenizer-Nano-ONNX both `apache-2.0`). The README's license section hedges ('if the LICENSE file is not yet published, treat as not licensed for redistribution'); the LICENSE file exists, so that caveat appears moot, but keep a copy of the LICENSE commit hash when integrating. **Surprises:** (1) the built-in voice presets are voice clones of real people / characters (including a preset named `Trump` and several Japanese anime-style names); no consent or provenance statement was found, so do not ship those presets - supply your own licensed reference audio. (2) There are no Korean presets; Korean here is zero-shot cross-lingual using the English `Ava`/`Adam` prompts, so the voice carries an English-speaker timbre and ASR shows slightly more Korean errors than Supertonic. (3) Upstream ONNX runtime still imports PyTorch/torchaudio (needed only to run these samples, not on Android). (4) The ONNX weights are fp32, ~763 MB - large for an app bundle (would need download-on-demand or quantisation). Samples are sampled (seed 1234), so reruns differ slightly. WeTextProcessing was disabled (not installable here); the simple built-in normaliser was used, so Korean numerals like `1분` stay as written.
- **Kitten TTS 0.8**: Apache-2.0 (https://huggingface.co/KittenML/kitten-tts-nano-0.8-int8, https://huggingface.co/KittenML/kitten-tts-mini-0.8, https://github.com/KittenML/KittenTTS; package https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models). The sherpa-onnx names in the task (`kitten-nano-en-v0_2-fp16`, `kitten-mini-en-v0_1-fp16`) are older model versions (nano 0.2 / mini 0.1); real 0.8 packages exist (`kitten-nano-en-v0_8-int8`, `kitten-mini-en-v0_8`), so those were used. The nano package is int8 (not the larger fp32 63.8 MB variant); mini is fp32 only. Kitten phonemizes via espeak-ng (GPL-3.0). sherpa-onnx 2.0 dropped the bundled espeak-ng from Python, so English text was phonemised with the community `lexicon-en-us.txt` from the sherpa-onnx `tts-models` release instead (no OOV words in these sentences). Check the lexicon/CMUdict license before shipping; a bundled-espeak build (GPL) would be a separate licensing question.
- **Kokoro**: Apache-2.0 (https://huggingface.co/hexgrad/Kokoro-82M). The task suggested `kokoro-int8-multi-lang-v1_1`, but its English voices are only `af_maple`, `af_sol`, `bf_vale` (no male English voice) and it is tuned for Chinese; `kokoro-int8-multi-lang-v1_0` (53 voices, 132 MB archive) was used for a female and a male English voice. It was run with the same `lexicon-en-us.txt` rather than espeak (the package's own lexicon skips plurals such as `mushrooms`, `minutes`). Kokoro does not support Korean. Training-data/voice-pack provenance is not addressed by the license text; upstream states Apache-2.0 only.
- All RTFs are for a desktop CPU with 4 threads. Phone CPUs are typically several times slower; treat these only as a relative ordering.
- ASR proxy: English transcripts of all five models are essentially exact. Korean: Supertonic transcripts are exact except trivial spacing/`세요세요` stutter artefacts; MOSS drops or mangles some words (e.g. K1 `파스타 분 남았어요`/`버섯스타`, K3 `후량` for `후렴`). SenseVoice errors can also be ASR errors, so listen to confirm.

## Reproduce

Downloaded models and venvs live outside the repo (scratchpad). Scripts (run with `python3 -I` and absolute paths, never from inside a downloaded directory):
- `scripts/gen_sherpa.py <models_root> <out_dir>` - Supertonic 3, Kitten nano/mini, Kokoro via `sherpa-onnx` (venv: sherpa-onnx, onnxruntime, numpy, soundfile, huggingface_hub). Model dirs: `supertonic/`, `kitten-nano/`, `kitten-mini/`, `kokoro/` (each holds `size.txt` + the unpacked release archive) and `lexicon-en-us/lexicon-en-us.txt`, from https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models. Supertonic settings: `num_steps=8`, `speed=1.0`.
- `scripts/gen_moss.py <moss_repo_dir> <moss_onnx_dir> <out_dir>` - imports upstream `onnx_tts_runtime.py` from a shallow clone of https://github.com/OpenMOSS/MOSS-TTS-Nano (reviewed before running; venv additionally needs CPU `torch`, `torchaudio`, `sentencepiece`).
- `scripts/build_compare.py`, `scripts/asr_check.py` (needs SenseVoice int8 from the sherpa-onnx `asr-models` release), `scripts/build_readme.py`.
